# sns-growth

SNS 運用アカウント（X / Instagram / TikTok / YouTube Shorts）を立ち上げて伸ばすプロジェクト。

## 進め方

1. **リサーチ** — ジャンル候補を出し、競合・需要・自分の強みで絞り込む（[strategy/research.md](strategy/research.md)）
2. **ポジショニング決定** — 誰に何を届けるアカウントか（[strategy/positioning.md](strategy/positioning.md)）
3. **アカウント立ち上げ** — [accounts/](accounts/) のチェックリストに沿って作成
4. **投稿 → 計測 → 改善** — [strategy/kpi.md](strategy/kpi.md) の指標を週次で記録
